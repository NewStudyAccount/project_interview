## 使用建议

1. **按知识块复习**: 每个文件独立完整，可按模块逐个攻克
2. **关注高频题**: 文件中标注了高频考点，优先掌握
3. **理解原理**: 不要死记硬背，理解底层原理才能应对追问
4. **动手实践**: 结合项目经验回答，展示实战能力
